# Agent notes — HPproto UI

This directory is the HP Demo Day prototype (bowling sheet + trade daily intake).

1. Read `LOCAL-DEV.md` before starting the app.
2. Use the `local-startup` skill to run localhost.
3. Do not use Trimble Identity on localhost. TID is only for the VPN/VM deploy.
4. Put UI changes on a branch and open a PR to `main`.
